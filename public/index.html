How it works
  • Connect Google Drive once — stays connected permanently
  • All synced DWGs and PDFs are stored locally in your browser
  • Once synced, view all files with no internet connection
  • Run sync each morning after Deswik exports DWGs to Google Drive
  • Only new or changed files are re-downloaded
  • On iPad/iPhone: tap Share then Add to Home Screen for a full-screen app
  • On PC: click the install icon in the browser address bar
